Synchronisation Serveur & GitHub
Le serveur étant un dépôt GitHub statique (bastonus/jgabc), vos avis sont mémorisés localement et peuvent être intégrés au dépôt :
1. Ticket GitHub (1-Clic sans configuration) Recommandé

Ouvre un ticket GitHub pré-rempli avec vos avis. Le workflow GitHub Actions place automatiquement vos avis dans la file d'attente de relecture (pipeline/reviews/pending/) pour validation par les mainteneurs avant publication.

2. Enregistrement direct (Token GitHub) Mainteneur

Pousse un commit directement sur la branche main sans ouvrir de ticket. Token mémorisé localement dans votre navigateur.
